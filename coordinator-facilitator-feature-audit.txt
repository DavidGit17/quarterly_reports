- Delete button per uploaded file
- File constraints text displayed

Validation Actions:

- Field type validation (text, number, date format)
- Rating range validation
- No server-side validation error display on form

9. REAL USER WORKFLOW
================================================================================

9.1 Coordinator Workflow
-------------------------
1. LOGIN: /auth -> enter credentials -> POST /api/auth/login
2. LANDING: / (Dashboard) -> see welcome + recent reports
3. SUBMIT REPORT (two paths):
   Path A (primary):
     - Click "New Report" card
     - If assigned project: go directly to /form/{slug}
     - If no project: /select -> type project -> select quarter -> /submit-report
   Path B (legacy):
     - /select -> type project -> select quarter -> /submit-report
4. FILL FORM: Complete dynamic fields (text, number, choice, rating, date, file)
5. SUBMIT: Click "Submit" -> progress bar -> success modal -> auto-redirect to /
6. VIEW REPORTS: Dashboard table or /my-reports -> click "View" on a row
7. SEARCH: Type quarter name in search box -> filtered table
8. MANAGE PROFILE: Click avatar -> "Profile" -> view/edit image, change password
9. LOGOUT: Click avatar -> "Logout" -> redirected to /auth

9.2 Facilitator Workflow
-------------------------
1. LOGIN: /auth -> enter credentials -> POST /api/auth/login
2. LANDING: /f (Dashboard) -> see welcome + recent reports
3. SUBMIT REPORT (two paths):
   Path A (primary):
     - Click "New Report" card
     - If assigned project: go directly to /f/form/{slug}
     - If no project: /f/select -> /f/submit-report
   Path B (legacy):
     - /f/select -> /f/submit-report
4. FILL FORM: Same dynamic form fields as coordinator
5. SUBMIT: Click "Submit" -> success modal -> auto-redirect to /f
6. VIEW REPORTS: Dashboard table or /f/my-reports -> "View"
7. SEARCH: Type quarter name -> filtered table
8. MANAGE PROFILE: Click profile icon -> /profile -> edit image, change password
9. LOGOUT: Profile page -> "Logout"

9.3 Missing Workflow Elements
------------------------------
- No email notification integration for form assignments
- No draft saving capability
- No report editing after submission
- No report approval/rejection workflow
- No deadline awareness (no due dates shown)
- No confirmation before form submission
- No offline support for form filling

11. FEATURES LIKELY UNNECESSARY
================================================================================

11.1 Redundant Pages
---------------------
- /submit-report and /f/submit-report (legacy): These duplicate /form/[project]
  functionality but with fewer field types (no choice, rating, date). The
  /form/[project] page is the primary and more complete implementation.
  Recommendation: These are dead code paths after /form/[project] was built.

- /select and /f/select: Only exist to support the legacy /submit-report flow.
  If /form/[project] fully replaces the legacy path, these are unnecessary.

11.2 Redundant Elements
------------------------
- "View Reports" in form navbar (facilitator version): User is already on
  the form page; "View Reports" should be accessible from the dashboard.
- Profile icon as simple link (facilitator): Coordinator has a dropdown with
  profile + logout; facilitator only has a link to /profile with no logout
  shortcut.

11.3 Questionable Features
---------------------------
- Simulated upload progress bar: Shows fake progress (0-90% via setInterval
  with random increments), then jumps to 100%. Provides no real information.
- Preview mode (?preview=true): Only triggered by direct URL manipulation;
  no UI element exposes this feature to admin users naturally.
