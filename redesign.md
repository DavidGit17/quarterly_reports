UI REDESIGN REQUEST — ONLY FOR COORDINATOR / FACILITATOR FORM EXPERIENCE

Read and follow flow.md.

IMPORTANT:

This redesign applies ONLY to:

- coordinator form pages
- facilitator form pages
- form preview
- submission screen
- form response pages / My Reports pages if relevant

DO NOT redesign:

- admin dashboard
- admin sidebar
- admin analytics
- admin tables
- admin management pages

Admin UI can remain mostly unchanged.

---

DESIGN GOAL

Make the coordinator/facilitator form experience feel similar to Microsoft Forms.

Use a clean, modern, soft, professional form UI.

The form should feel visually separate from the page background.

---

BACKGROUND STYLE

Use a soft subtle gradient background.

Direction:

light mint / soft cyan / pale blue / soft gray.

Example palette direction:

- #F7FAFA
- #EAF6F3
- #DFF4F6
- #EDF7FF

Gradient should be subtle and professional.

Not flashy.

---

FORM CONTAINER / CANVAS

The form itself should be visually separated from the background.

Use:

- floating white surface
- clean card container
- subtle elevation
- gentle shadow
- comfortable spacing

Visual structure:

soft background

↓

centered form canvas

↓

sections + fields

The form should feel like a dedicated work surface.

Similar to Microsoft Forms.

---

INPUT DESIGN

Use smoother enterprise form styling.

Inputs should have:

- soft borders
- comfortable height
- clean spacing
- smooth rounded corners

Border radius:

12–16px.

Use subtle focus styling.

Soft focus ring.

Premium clean appearance.

---

SECTIONS

Form sections should feel clearly grouped.

Use:

- section separation
- comfortable vertical spacing
- clean hierarchy
- subtle dividers where useful

---

BUTTONS

Use modern button styling.

Primary actions:

- muted deep blue
- smooth border radius
- soft hover transition

Secondary buttons:

- outline / ghost style

---

TYPOGRAPHY

Clean enterprise typography.

Clear hierarchy:

- form title
- section title
- question text
- helper text

Use strong readability.

---

SPACING

Increase breathing room.

Use:

- generous margins
- larger gaps
- comfortable padding
- cleaner layout rhythm

Avoid cramped forms.

---

FORM PREVIEW

Apply same visual style to:

- desktop preview
- mobile preview

Preview should closely resemble actual respondent experience.

---

POST SUBMISSION SCREEN

Redesign submission success experience.

After submit:

Your response was submitted.

Use:

- clean confirmation state
- soft success styling
- centered layout
- clear next actions

Options:

- Save my response
- Submit another response

Should feel polished and professional.

---

MY REPORTS PAGE (Coordinator / Facilitator side only)

Apply lighter modernization.

Use:

- cleaner cards
- better spacing
- smoother inputs/buttons
- softer surfaces

But keep functionality unchanged.

---

IMPLEMENTATION RULES

1. Reuse existing UI components where possible.

2. Avoid touching admin dashboard styling.

3. Prefer component-level styling changes limited to coordinator/facilitator pages.

4. Keep accessibility and responsiveness intact.

5. Generate short redesign plan before coding.

Then implement incrementally.
