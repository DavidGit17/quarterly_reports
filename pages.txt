PHASE 1 — REMOVE ARTIFICIAL DELAYS

The audit identified forced delays in:

- Login Success Flow
- OTP Verification Success Flow
- Reset Password Success Flow

Search for:

setTimeout

setInterval

artificial progress timers

forced redirect delays

minimum loading durations

Examples:

await new Promise(...)

setTimeout(...)

animated progress timers

Current behavior:

Success
↓
Artificial wait
↓
Redirect

Target behavior:

Success
↓
Immediate redirect

Requirements:

- Keep animations if desired
- Do not block navigation
- Allow redirect as soon as backend succeeds

Report every removed delay.

PHASE 2 — ELIMINATE REPEATED /api/auth/me REQUESTS

The audit identified repeated authentication lookups.

Examples:

Dashboard

Forms

Users

Storage

Reports

Coordinator Pages

Profile

Requirements:

Identify every page requesting:

GET /api/auth/me

Determine whether the user is already available through:

- Auth Context
- Session Provider
- Existing state

Refactor to eliminate duplicate auth requests.

Goal:

User information should be fetched once and reused.

Do not change authentication behavior.
