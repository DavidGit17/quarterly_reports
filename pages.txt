MODULE PURPOSE

This page allows Administrators to manage storage allocations, upload permissions, and file upload restrictions for all users in the system.

Supported roles:

- Admin
- Coordinator
- Facilitator

Storage allocation is an application-level quota system and is not directly tied to AWS S3 allocation.
